# PR前チェックリスト（Salesforce）

## ガバナ制限
- ループの中に SOQL・DML がないか
- 200件まとめて処理されても動くか（テストで確認しているか）
- 不要な項目まで SELECT していないか

## セキュリティ
- クラスは `with sharing` か。`without sharing` なら理由がコメントにあるか
- SOQL に `WITH USER_MODE`、DML に `AccessLevel.USER_MODE` を使っているか
- ユーザー入力を SOQL に文字列連結していないか
- レコードID・URL・メールアドレス・APIキーが直書きされていないか

## テスト
- 新しい処理にテストクラスがあるか、Assert で結果を確認しているか
- 一括（200件）テストと境界値テストがあるか
- カバレッジは 75% 以上（社内目標 85%）か
- `SeeAllData=true` を使っていないか

## メタデータ
- 新しい項目・オブジェクトに、権限セットでのアクセス権が設定されているか
- 項目の表示ラベル・説明が日本語で書かれているか
- 同じオブジェクトでフローとトリガーが同じ項目を更新していないか
- `.forceignore` に入れるべきファイルがコミットされていないか

## 後片付け
- `System.debug` の消し忘れがないか
- コメントアウトしたコードが残っていないか
- リリース時に手作業が必要なら、PR説明の「リリース時の注意」に書いたか
