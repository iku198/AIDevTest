# PR前チェックリスト

## 規約
- 命名・フォルダ構成が coding-rules に沿っているか
- 1関数・1ファイルが大きくなりすぎていないか

## 正しさ
- 仕様（docs/superpowers/specs/ や Issue）の内容をすべて満たしているか
- 境界値（0件、空文字、最大値、null）を考慮しているか
- エラー処理が抜けていないか、握りつぶしていないか

## テスト
- 新しい処理・修正したバグにテストがあるか
- テストが実際に失敗→成功を確認したものか（最初から通るだけのテストではないか）

## セキュリティ
- APIキーやパスワードが直書きされていないか
- ユーザー入力をそのままSQL・コマンド・HTMLに入れていないか
- ログに個人情報やトークンを出していないか

## 後片付け
- console.log・デバッグ用コード・コメントアウトしたコードが残っていないか
- 不要になったファイルや依存パッケージを消したか
- README や設定例の更新が必要ないか
